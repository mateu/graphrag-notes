# Atlas project: fictional sample notes

These demonstration notes describe a fictional project. They contain no private
notes, credentials, customer details, or imported conversations. Import this file
to try GraphRAG Notes, then search for "What is the Atlas project launch plan?".

## Launch plan

The Atlas project launch plan has three stages: test the searchable notebook
with the internal team, invite a small pilot group, then open access after the
pilot feedback is addressed. The launch depends on a working setup guide and
clear links from search results back to the original notes. The team will review
readiness at the end of the pilot rather than commit to a calendar date.

## Pilot feedback

The Atlas pilot group will use the notebook to capture meeting decisions and
find them later. Each participant should install the CLI, import the sample,
search for the launch plan, and inspect the source. Success means a participant
can retrieve the launch stages without asking the project team for help.

## Decisions and follow-ups

Atlas stores source notes locally and uses local inference for embeddings and
entity extraction. The demonstration uses a 1024-dimension embedding model.
The team will keep the original Markdown files so that note content remains
editable and can be reimported after a change. Network access is a separate
follow-up after the local workflow is easy to use.
